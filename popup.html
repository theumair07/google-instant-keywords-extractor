Turn On/Off Extension
Please visit Google.com to use this extension
How to Use:
  1. Please visit Google.com and type anything in the search bar.
  2. You will see a Copy button next to each suggestion.
  3. Use checkboxes to select multiple suggestions.
  4. Use the Copy Selected button to copy only checked suggestions.
  5. Use the Copy All button to copy all suggestions at once.
  6. Use the Deselect All button to uncheck all selections.
